# HabiTree: Procedural 3D Habit Tracker Studio

An interactive parametric 3D CAD design tool that generates customized, modular 3D-printable **Habit Tracker Trees** for any habit streak goal (14 to 100 days) across 5 distinct aesthetic styles.

---

## 1. Quick Start

### A. Launch Interactive 3D Web Studio
Start the local server:
```bash
python3 tools/habitree/server.py 8080
```
Open your browser at: **`http://localhost:8080`**

From the web dashboard you can:
- Select between 5 aesthetic styles.
- Adjust the habit day streak target (14, 30, 50, 60, 100 days).
- Roll random organic seeds (`🎲 Roll`) for procedural variations in trunk sway, branch fork angles, and cluster rotations.
- Orbit, pan, and zoom in real-time 3D.
- Scrub the **Growth Timeline** to watch the tree build piece-by-piece from Day 1 to Day $N$.
- Use the **Exploded View Slider** to inspect the internal sliding dovetails.
- One-click export of Bambu Lab A1 slicing plates, all individual day STLs (ZIP), or master STEP files.

### B. Command-Line Interface (CLI)
You can also generate trees directly from the terminal:
```bash
# Generate 30-day Zen Bonsai with seed 42
python3 tools/habitree/cli.py --style zen_bonsai --pieces 30 --seed 42

# Generate 50-day Sakura Cherry Blossom Tree with seed 108
python3 tools/habitree/cli.py --style sakura --pieces 50 --seed 108

# Generate 14-day Ghibli Fruit Tree
python3 tools/habitree/cli.py --style ghibli_fruit --pieces 14 --seed 7

# Generate 100-day Autumn Japanese Maple
python3 tools/habitree/cli.py --style autumn_maple --pieces 100 --seed 999
```

## 3. Engineering & Slicing Specifications

All trees generated by the tool strictly adhere to:
- **0 Collisions ($0.000\text{ mm}^3$)**: Mathematically validated via OpenCASCADE Boolean intersection.
- **Precision Tolerances**:
  - $0.15\text{ mm}$ side sliding clearance on male/female dovetails.
  - $0.20\text{ mm}$ axial relief on socket floors.
  - $0.15\text{ mm}$ circumferential seam clearance between adjacent wedges.
- **100% Support-Free 3D Printing**: All overhang angles $\le 45^\circ$, enabling clean prints directly on the textured PEI sheet without support material.
- **Bambu Lab A1 Ready**: Automated nesting into 3 production plates organized by filament color (Base/Trunk, Branches, Canopy/Accents).
